# CubeFall

**CubeFall** — аркада в стиле «пузырьковой стрелялки» с физикой отскока от стен. Запускай кубики снизу, формируй группы из 3+ одинаковых цветов, обрывай сцепки с потолком и очищай поле до полной победы!

> **Версия 1.6.0** — одноразовое PWA (`index.html` + `sw.js` + `manifest.json` + иконки).

---

## ✨ Особенности

- 🎯 **Стреляй и соединяй** — запускай кубики по прямой с отскоком от боковых стен, чтобы попасть в нужное место.
- 🧩 **Группы 3+** — собирай 3 и более кубиков одного цвета, чтобы они исчезли.
- 💥 **Обрыв** — кубики, потерявшие связь с потолком, падают и приносят бонусные очки + бесплатный ход.
- 🔥 **Комбо** — уничтожай группы подряд для множителя очков.
- 🌟 **Почти чисто** — если на поле остался только один ряд, даётся разовый бонус +300.
- 🏆 **Полная очистка** — очисти всё поле и получи **бонус за победу** (см. формулу ниже).
- ⏱️ **Бонус за скорость** — чем быстрее полная очистка, тем больше бонусных очков.
- 🎮 **Геймпад** — полная поддержка контроллеров (левый стик / D-pad для прицеливания, A — выстрел, B — поменять цвет, Start — пауза, Select — подтвердить рестарт).
- 🌐 **Двуязычность** — русский и английский интерфейс (переключение кнопкой `RU/EN`).
- 🔊 **Звуковые эффекты** — синтезированные звуки через Web Audio API (без внешних файлов).
- 📊 **Таблица рекордов** — топ-5 лучших результатов сохраняется локально (`localStorage`).
- 📱 **PWA** — устанавливается как приложение на телефон или десктоп; работает офлайн (Service Worker со стратегией `stale-while-revalidate`).
- 🖥️ **Чёткая графика на всех экранах** — DPR-aware canvas и atlas (ретина/HiDPI) без ущерба быстродействию.
- ♿ **Доступность** — поддержка `prefers-reduced-motion`, авто-пауза при потере видимости вкладки, semantic ARIA-разметка.
- 🧊 **Режим «Frosted Glass»** — переключаемый стиль кубиков (клик по подписи «conceptual project» внизу рамки).

## 🎮 Как играть

| Действие | Мышь / Тач | Геймпад |
|---|---|---|
| Прицелиться | Наведите курсор на поле / тяни-прицеливание пальцем | Левый стик / D-pad |
| Выстрелить | ЛКМ / тап (touch: отпустить после drag) | Кнопка **A** |
| Поменять цвет | ПКМ (contextmenu) | Кнопка **B** |
| Пауза | Кнопка ⏸ в интерфейсе | Кнопка **Start** |
| Подтвердить рестарт | Кнопка паузы → Restart → YES | **Select → A** |

### Правила

1. **Стрельба** — нажмите на поле, чтобы запустить кубик. Он летит по прямой с отскоком от боковых стен. Боковые отскоки сопровождаются «рикошетным» звуком.
2. **Совпадение** — если после приземления группа из 3+ кубиков одного цвета касается друг друга (по горизонтали или вертикали), она уничтожается.
3. **Обрыв** — кубики, не соединённые с потолком через цепочку соседей, падают и дают бонусные очки + бесплатный ход (множитель 1.5× для ≥10 кубиков — «Мега обрыв»).
4. **Спуск** — каждые 4 хода сверху появляется новый ряд кубиков.
5. **Конец игры** — если кубики достигают самого низа (последний ряд заполнен), игра окончена. Спустя 2.5 секунды показывается оверлей.
6. **Победа** — если очистить поле полностью, вы получаете **бонус за победу** и звание победителя! 🌟

## 🏆 Подсчёт очков

### Группы и комбо

| Действие | Очки |
|---|---|
| Группа 3 кубика | 10 × N |
| Группа 4 кубика | 14 × N |
| Группа 5–6 кубика | 18 × N |
| Группа 7+ кубика | 25 × N |
| Множитель комбо | ×(1 + 0.5×(combo−1)), макс ×3 |
| Обрыв (disconnect) | 15 × N |
| Мега обрыв (≥10 кубиков) | 15 × N × (1.5 + 0.1×(N−10)), макс ×2.5 |
| Почти чисто (1 ряд остался) | +300 (разово за партию) |

### ⏱️ Бонус за быструю победу (новое в v1.6)

За полную очистку поля игроку начисляется **бонус за победу**, размер которого **обратно пропорционален затраченному времени**:

```
bonus = max(50 000, 200 000 − minutes × 2 500)
```

| Время | Бонус |
|---|---|
| ≤ 3 мин (молниеносно) | ~200 000 |
| 10 мин | 175 000 |
| 30 мин | 125 000 |
| 1 час | 50 000 (минимум) |
| 5 часов | 50 000 (минимум) |

В оверлее победы показывается затраченное время, начисленный бонус и скоростной тир («Молниеносно!» / «Отличное время!» / «Победа!»).

## 🛠️ Технические детали

- **Однофайловое PWA** — вся игра в одном `index.html`; `sw.js` и `manifest.json` — служебные.
- **Canvas 2D** — отрисовка через предрендеренный atlas (5 цветов × 1 спрайт), что снижает количество вызовов `drawImage` до 1 на куб.
- **DPR-aware rendering** — Canvas и atlas масштабируются под `window.devicePixelRatio` (кап в 3) для чёткой картинки на retina/HiDPI без роста нагрузки сверх меры.
- **Pointer Events** — единый API для мыши, тача и геймпада (через crosshair-прицел).
- **Web Audio API** — все звуки синтезируются в рантайме (oscillator + gain envelope). Звук полностью отключаемый.
- **Service Worker** — стратегия `stale-while-revalidate` для статики и `network-first` для навигации; `self.skipWaiting()` + `clients.claim()` для мгновенного обновления.
- **Local Storage** — хранит таблицу рекордов (`cubefall_lb`), выбранный язык (`cubefall_lang`) и настройку звука (`cubefall_sound`).
- **Безопасность** — все пользовательские данные (имя в LB, очки и т.д.) экранируются через `esc()` перед вставкой в DOM; `loadLB` валидирует структуру и типы полей.
- **Без утечек** — все `setTimeout`-обёртки (`safeTimeout`, `bonusTimeout`, `victoryTimeout`) чистятся при рестарте.

### Доступность

- `@media (prefers-reduced-motion: reduce)` — отключает пульсацию звёзд и пульс паузы.
- Авто-пауза при потере видимости вкладки (`visibilitychange`), корректное смещение таймингов фаз и анимации при возобновлении.
- Semantic разметка: `<canvas role="application" aria-label="...">`, `aria-label` на кнопках.
- Touch-friendly: минимальные 44px таргеты, `touch-action: none` на канвасе.

### Адаптивная типографика

Все интерфейсные сообщения используют `clamp(min, vw, max)` для плавного масштабирования шрифта от десктопа до мобильного. На мобильных (<540px) и сверхмалых (<360px) экранах добавлены агрессивные переопределения, чтобы сообщения всегда помещались в свои контейнеры.
