# 🎯 Кубопад — CubeFall PWA

Легкая медитативная аркада с падающими кубиками, работает оффлайн, без магазинов приложений.

## ✨ Особенности игры

- **Аркадный геймплей:** реагируй на падающие объекты, правая кнопка мыши меняет кубик
- **Система счёта:** отслеживай свой прогресс в реальном времени
- **PWA:** установка на устройство и работа без интернета
- **Мгновенный запуск:** никаких загрузок и установок через магазин
- **Мультиязычность:** переключение EN/RU
