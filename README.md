# Кубопад / CubeFall


**Кубопад (CubeFall)** — аркада в стиле «пузырьковой стрелялки», выполненная в эстетичном пиксельном дизайне. Цель игры — стрелять цветными кубиками снизу, формировать группы из 3+ одинаковых цветов и очищать поле до полной победы!

### Особенности

- 🎯 **Стреляй и соединяй** — запускай кубики с отскоком от стен, чтобы попасть в нужное место
- 🧩 **Группы 3+** — собирай 3 и более кубиков одного цвета, чтобы они исчезли
- 💥 **Обрыв** — кубики, потерявшие связь с потолком, падают и приносят бонусные очки + бесплатный ход
- 🔥 **Комбо** — уничтожай группы подряд для множителя очков
- 🏆 **Полная очистка** — очисти всё поле и получи +100 000 бонусных очков!
- 🎮 **Геймпад** — полная поддержка контроллеров (левый стик / D-pad для прицеливания, A — выстрел, B — поменять цвет)
- 🌐 **Двуязычность** — русский и английский интерфейс
- 🔊 **Звуковые эффекты** — синтезированные звуки через Web Audio API
- 📊 **Таблица рекордов** — топ-10 лучших результатов сохраняется локально
- 📱 **PWA** — устанавливается как приложение на телефон или десктоп

## 🎮 Как играть

| Действие | Мышь / Тач | Геймпад |
|---|---|---|
| Прицелиться | Наведите курсор на поле | Левый стик / D-pad |
| Выстрелить | ЛКМ / тап | Кнопка A |
| Поменять цвет | ПКМ / долгое нажатие | Кнопка B |
| Пауза | Кнопка ⏸ в интерфейсе | Кнопка Start |
| Перезапуск | Кнопка паузы → подтвердить | Start → A |

### Правила

1. **Стрельба** — нажмите на поле, чтобы запустить кубик. Он летит по прямой с отскоком от боковых стен.
2. **Совпадение** — если после приземления группа из 3+ кубиков одного цвета касается друг друга (по горизонтали или вертикали), она уничтожается.
3. **Обрыв** — кубики, не соединённые с потолком через цепочку, падают и дают бонусные очки + бесплатный ход.
4. **Спуск** — каждые 4 хода сверху появляется новый ряд кубиков.
5. **Конец игры** — если кубики достигают самого низа, игра окончена.
6. **Победа** — если очистить поле полностью, вы получаете +100 000 очков и звание победителя! 🌟
